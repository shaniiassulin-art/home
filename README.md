# הבית שלנו

אפליקציה לניהול משימות ניקיון ותחזוקה בבית: כל משימה עם תדירות, תאריך ביצוע אחרון, חדר וחשיבות, והאפליקציה מחשבת מתי הפעם הבאה ומה באיחור.

## מה יש בה
- סימון "בוצע" בלחיצה אחת, עם ביטול
- סידור לפי דחיפות (באיחור / להיום / השבוע / בהמשך) או לפי חדר
- מד "בזמן" וספירות שמסננות את הרשימה
- דחייה ביום או בשבוע, ותאריך יעד ידני
- היסטוריית ביצועים וממוצע בפועל לכל משימה
- הערות, תאריך עברי, מצב כהה

## הרצה
הכול בקובץ אחד: `index.html`. אפשר לפתוח אותו ישירות בדפדפן או להפעיל GitHub Pages על הענף `main`.

## שמירת נתונים
- כשהאפליקציה פתוחה כ־Artifact ב־Claude, המשימות נשמרות במסד הנתונים של ה־Artifact ומסונכרנות בין מכשירים.
- מחוץ ל־Claude (למשל ב־GitHub Pages) היא עוברת למצב מקומי ושומרת בדפדפן בלבד (`localStorage`).
- בפתיחה הראשונה בדפדפן חדש נטענת רשימת המשימות ההתחלתית מ־`seed.js` (36 משימות). אחרי זה הדפדפן שומר את השינויים שלכם, והקובץ לא נטען שוב.
