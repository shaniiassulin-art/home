# הבית שלנו

אפליקציה לניהול משימות ניקיון ותחזוקה בבית: כל משימה עם תדירות, תאריך ביצוע אחרון, חדר וחשיבות, והאפליקציה מחשבת מתי הפעם הבאה ומה באיחור.

## מה יש בה
- סימון "בוצע" בלחיצה אחת, עם ביטול
- סידור לפי דחיפות (באיחור / להיום / השבוע / בהמשך) או לפי חדר
- מד "בזמן" וספירות שמסננות את הרשימה
- דחייה ביום או בשבוע, ותאריך יעד ידני
- היסטוריית ביצועים וממוצע בפועל לכל משימה
- הערות, תאריך עברי, מצב כהה, אייקון להוספה למסך הבית

## מבנה
- `public/` – האתר עצמו (`index.html`, אייקונים, `manifest.webmanifest`)
- `netlify/functions/tasks/` – השרת: שומר את המשימות ב־Netlify Blobs
- `netlify.toml` – הגדרות הפריסה

## סנכרון
באתר ב־Netlify כל המשימות נשמרות בשרת, ולכן כל מכשיר שפותח את הקישור רואה את אותם נתונים.
- כל שינוי נשלח לשרת מיד. האפליקציה מושכת עדכונים כל 15 שניות וכשחוזרים אליה.
- בלי חיבור, השינויים נשמרים במכשיר ונשלחים אוטומטית כשהחיבור חוזר.
- בפעם הראשונה שהשרת ריק, הוא נטען ב־36 המשימות ההתחלתיות (`netlify/functions/tasks/seed.mjs`).

ה־API: `GET /api/tasks`, `PUT /api/tasks/:id`, `DELETE /api/tasks/:id`.
